Қорытынды жоба

10 сабақтағы білімді қолданып, өз бағдарламаңды жаса. Мысал: «Санды тап» ойыны.

Жақсы жобада кемінде input(), if, цикл және функция болсын.

Сабақтарға өту
sanды_тап.py
import random
сан = random.randint(1, 10)
жауап = int(input("Санды тап (1-10): "))
if жауап == сан:
    print("Жарайсың!")
else:
    print("Қате! Сан:", сан)
